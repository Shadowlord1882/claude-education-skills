# Layout templates

## Question paper

```
# <Grade> <Subject> Practice Test: Question Paper

## Paper details
**<Level> · <Subject> · Grade <N> · Practice Paper (<difficulty>)**
Name: ______________________  Class: ________  Date: ____________
**Time:** <duration>  **Total:** <marks> marks

**Instructions**
- Answer all questions in the spaces provided.
- Show all working in calculations and write the unit with every answer.
- The number of marks for each question is shown in brackets [ ].
- You may use a calculator.            (drop this line if the paper is non-calculator)

| Section | Type | Marks |
| --- | --- | --- |
| A | ... | .. |

**Topics in scope:** <topic 1> · <topic 2> · ...

## Section A: <type> [<marks> marks]
<instruction line, e.g. Circle the one correct answer. [1 mark each]>

**A1.** <question>
A. ...  B. ...  C. ...  D. ...

## Section B: ... 
**B1. <short title>**
(a) <question>. [2]
______________________________________________________________
```

Conventions:

- Number questions by section (A1, B3, C2, D1) with parts (a), (b), (i), (ii).
- Marks in square brackets at the end of each part; for a multi-part question, the question title may carry the total, e.g. `**D1. Solubility investigation** [8]`.
- Ruled lines under every written answer, sized by the table in `references/answer-space.md` (about 2 lines per mark for explanations, 1 per mark for short statements, 3 blank working lines per mark plus an `Answer: ____ (unit)` line for calculations). Each line is its own ruled line, not one long run of underscores.
- Put the useful-equations line at the top of the calculations section for lower grades.
- Tables of results go in the question, with units in the column headings.
- Keep formatting plain and printable: no colour dependence, no decorative blocks.

## Mark scheme

```
# <Grade> <Subject> Practice Test: Mark Scheme

Answer key for the <Grade> <Subject> Practice Test (<marks> marks). Accept equivalent wording; units are required for calculation marks.

## Section A: Multiple choice [<marks> marks]
1 mark each.
| A1 | A2 | A3 | ... |
| --- | --- | --- | --- |
| C | C | B | ... |

## Section B: ... [<marks> marks]
| Q | Answer | Marks |
| --- | --- | --- |
| B1(a) | Any two: ...; ...; ... | 2 |

## Section C: Calculations [<marks> marks]
| Q | Working and answer | Marks |
| --- | --- | --- |
| C1(a) | 4 min = 240 s (1); 1200 ÷ 240 (1); = 5 m/s (1) | 3 |
```

Conventions:

- One row per question part, in the same order as the paper, so a marker can run down both side by side.
- Write marking points with the mark each earns in brackets, and use "Any two:" or "Any three:" for open lists.
- Write accepted ranges for graph readings ("About 74 g, accept 72–76 g") and alternative acceptable wordings ("accept ..."; "do not accept ...").
- Calculations: show the working marks (M) and answer mark (A) and the unit; allow error carried forward.
- Include the expected shape and key points for any plot or sketch.
- Section totals must match the paper; if they do not, fix one of them before delivering.
